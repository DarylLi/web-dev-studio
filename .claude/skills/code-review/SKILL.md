# /code-review — Review Code

**Purpose:** Review a PR for correctness, structure, security, and adherence to path-scoped rules.

## Inputs
- A PR

## Steps
1. Check logic correctness and edge cases
2. Check adherence to relevant path-scoped rules
3. Check test coverage
4. Approve or request changes with specific, actionable comments

## Outputs
- Review comments + approve/request-changes

## Agents Invoked
- frontend-lead
- backend-lead
