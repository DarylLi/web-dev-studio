# /accessibility-audit — Run an Accessibility Audit

**Purpose:** Audit a feature against WCAG 2.1 AA.

## Inputs
- A feature or flow

## Steps
1. Check semantic HTML/ARIA usage
2. Check color contrast and focus order
3. Check keyboard-only and screen-reader usability

## Outputs
- An accessibility audit report

## Agents Invoked
- accessibility-specialist
