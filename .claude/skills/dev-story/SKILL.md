# /dev-story — Implement a Story

**Purpose:** Implement a single story end-to-end (frontend and/or backend) following the approved design/API contract.

## Inputs
- A sprint-ready story

## Steps
1. Confirm acceptance criteria and API contract
2. Implement frontend and/or backend changes
3. Write unit tests
4. Open a PR referencing the story

## Outputs
- A PR implementing the story with tests

## Agents Invoked
- frontend-developer
- backend-developer
