# /create-stories — Create Sprint-Ready Stories

**Purpose:** Take epics and produce fully sprint-ready stories: acceptance criteria, design links, API contracts, test notes.

## Inputs
- An epic

## Steps
1. Break into implementable stories
2. Attach design links and API contract references
3. Confirm each story is estimable (INVEST check)

## Outputs
- Sprint-ready stories in production/stories/

## Agents Invoked
- product-lead
- frontend-lead
- backend-lead
