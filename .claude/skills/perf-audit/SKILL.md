# /perf-audit — Run a Performance Audit

**Purpose:** Audit frontend and/or backend performance against budgets.

## Inputs
- A feature or the full app

## Steps
1. Profile Core Web Vitals / API latency
2. Identify top bottlenecks
3. Recommend fixes ranked by impact/effort

## Outputs
- A performance audit report

## Agents Invoked
- frontend-performance-engineer
- performance-tester
