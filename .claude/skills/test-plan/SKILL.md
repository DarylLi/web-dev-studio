# /test-plan — Write a Test Plan

**Purpose:** Define what will be tested, how, and what 'pass' means for a feature/epic.

## Inputs
- A story/epic with acceptance criteria

## Steps
1. Identify test types needed (unit/integration/E2E/manual/perf/a11y)
2. Define pass/fail criteria per acceptance criterion
3. Identify edge cases and negative paths

## Outputs
- A test plan document

- qa-lead
