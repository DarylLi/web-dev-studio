# /prd — Write a Product Requirements Doc

**Purpose:** Turn a concept into a structured PRD: problem, goals, non-goals, users, success metrics, requirements.

## Inputs
- Concept brief or feature request

## Steps
1. Draft problem statement, goals, and non-goals
2. Define target users and success metrics
3. List functional and non-functional requirements
4. Get product-director sign-off for major scope

## Outputs
- docs/templates/prd.md filled in and saved to design/prd/

## Agents Invoked
- product-lead
- business-analyst
- product-director
