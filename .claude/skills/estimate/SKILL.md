# /estimate — Estimate Effort

**Purpose:** Produce a rough effort estimate for a story/epic to support sprint planning.

## Inputs
- A story or epic

## Steps
1. Break down into implementation sub-tasks
2. Estimate each sub-task
3. Flag high-uncertainty areas

## Outputs
- An estimate with confidence level

## Agents Invoked
- frontend-lead
- backend-lead
- qa-lead
