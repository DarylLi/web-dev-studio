# /user-stories — Write User Stories

**Purpose:** Break PRD requirements into INVEST-style user stories with acceptance criteria.

## Inputs
- An approved PRD

## Steps
1. Identify epics from the PRD
2. Break each epic into user stories (As a... I want... so that...)
3. Write acceptance criteria (Given/When/Then) for each story

## Outputs
- A backlog of user stories with acceptance criteria

## Agents Invoked
- product-lead
