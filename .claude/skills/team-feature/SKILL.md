# /team-feature — Orchestrate a Full Feature

**Purpose:** Coordinate product, design, frontend, backend, and QA together to ship one feature end-to-end.

## Inputs
- A feature request or epic

## Steps
1. product-lead drafts/confirms requirements
2. design-lead produces wireframes/mockups
3. backend-lead + frontend-lead confirm API contract
4. developers implement in parallel
5. qa-lead runs test plan and signs off
6. release-engineer prepares the release

## Outputs
- A shipped, tested feature

## Agents Invoked
- product-lead
- design-lead
- frontend-lead
- backend-lead
- qa-lead
- release-engineer
