# /prioritize — Prioritize the Backlog

**Purpose:** Rank backlog items using a transparent framework (e.g. RICE or MoSCoW) so priority isn't a gut call.

## Inputs
- Backlog of user stories/epics

## Steps
1. Score each item on reach/impact/confidence/effort (or MoSCoW)
2. Present ranked list with rationale
3. Confirm priority order with delivery-manager

## Outputs
- A prioritized backlog

## Agents Invoked
- product-lead
- business-analyst
- delivery-manager
