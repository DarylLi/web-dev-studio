# /ux-review — Review a UX Flow

**Purpose:** Critique an existing flow or mockup against usability heuristics and accessibility standards.

## Inputs
- A flow, mockup, or live feature

## Steps
1. Walk through the flow step by step
2. Flag friction points, unclear states, and accessibility gaps
3. Propose concrete fixes with priority

## Outputs
- A UX review report

## Agents Invoked
- design-lead
- accessibility-specialist
- ux-researcher
