# /bug-report — File a Bug Report

**Purpose:** Produce a clear, reproducible bug report.

## Inputs
- An observed defect

## Steps
1. Describe steps to reproduce
2. State expected vs actual behavior
3. Attach severity and environment info

## Outputs
- A filed bug report
